# 红队模式战绩总览

> **统计口径**：本机事实库 `$DSH_HOME/redteam/engagements/*/assets.db` 全量聚合（每个靶标一个独立库）。
> **统计截止**：2026-10-08　**演练周期**：2026-09 ~ 2026-10
> **去重规则**：资产/端口/漏洞按靶标库内唯一键（IP、IP+端口、漏洞条目）计数，跨靶标不去重；
> 内网段按私网 CIDR 跨靶标去重。得分命中与分值为服务端判定后的落库值。
> **脱敏说明**：本文件中的单位名一律用「行业-编号」代替，真实名称仅存在于本机事实库与各靶标目录，不随仓库分发。

## 五、本文件可复现的口径

- 全部数字可由本机事实库重算，不依赖任何截图或人工台账：
  ```sh
  node -e "const{DatabaseSync}=require('node:sqlite');/* 遍历 engagements/*/assets.db 聚合 */"
  ```
- 单个靶标的明细看该靶标目录：`$DSH_HOME/redteam/engagements/<单位>/assets.db`，
  控制台「报告」页签可导出该靶标的复现手册式报告（含报文、命令、证据截图）。
- 本文件不含任何真实单位名称、凭据、IP 与截图，可直接随仓库分发。
